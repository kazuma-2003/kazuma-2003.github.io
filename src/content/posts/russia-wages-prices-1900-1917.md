帝政ロシア末期の工場労働者の賃金と消費財の価格を集めたデータ集を作りました。散らばっていた統計書や研究書の数値を、県別・都市別・市場別に整理し、出典と注記を付けて1冊の Excel ブックにまとめています。このデータは Zenodo で公開しており、記事の末尾からダウンロードできます。

この統計は、私の革命と経済的状況の関係性を調査する研究プロジェクトの一環として整備されました。

## 内容

ブックは全25シートで、大きく次の5つに分かれます。

| 区分（シート）       | 内容                                                                                                                        |
| :------------ | :------------------------------------------------------------------------------------------------------------------------ |
| 賃金（W1〜W5）     | 工場労働者の県別・産業群別の年平均賃金（1913〜1915年）、工場監督区別の賃金（1900〜1914年）、全国の年収（1897〜1914年）、月額賃金（1913〜1917年）、ペテルブルク建設労働者の日給（1853〜1910年）       |
| 物価指数（P1〜P4）   | ペテルブルク小売物価指数（1867〜1916年）、小売・卸売の各種指数（1885〜1914年）、全露予算指数（1913〜1918年、1916〜1917年は月次）とそのサブ指数                                   |
| 価格（P5〜P16）    | モスクワ・ペテルブルクの参考価格、地域別の穀物価格（1900〜1915年）、タリンの賃金と市場価格、主要市場別の月次卸売価格（ライ麦・小麦・食肉・鰊・卵・バター・塩・砂糖・灯油など、1913〜1917年）、モスクワ小売の年平均価格（54品目） |
| 実質賃金（R1・CALC） | 実質賃金指数の諸推計（1913〜1921年）と、名目賃金を物価指数で割る計算例                                                                                   |
| 資料案内（SRC）     | 本ブックに収めていないが、オンラインで見られる一次資料（スキャン画像）の所在・ページ・URL                                                                            |

### 工場労働者の年収（全国、ルーブル）

| 1900 | 187.3 |         246.5 |             76.0 |
| 1905 | 199.0 |         235.2 |             84.6 |
| 1910 | 232.0 |         245.7 |             94.4 |
| 1913 | 257.2 |         257.2 |            100.0 |
| 1914 | 271.5 |         251.8 |            107.8 |

出典：Strumilin S.G., *Essays on the Economic History of Russia*（1960年）p.121（シート W3）

## 注意

* **転記について**：W1 と P9〜P16 は、一次資料のスキャン画像から目視で転記したものです。2026年10月9日に全セルを300dpiの画像と照合し直しましたが、個々の値に誤りが残る可能性はあります。重要な値は、SRC シートの URL から原資料の画像で確かめてください。
* **対象の偏り**：「年平均賃金」は罰金制度のある企業（全企業の約4分の1、労働者の約3分の2）だけの集計で、大きな工場に偏っています。
* **対象範囲の変化**：1914年以降の表はワルシャワ工場監督区（ポーランド）を含みません。1915年からはアジア・ロシアが加わります。
* **異常値**：1915年のウファの行は1914年と同じ値で、原資料が前年の値を転載したものと思われます。1915年のヴィテプスクとリヴォニアは、戦時の疎開の影響を受けた値です。
* **物価指数の違い**：基準年・対象品目・都市は系列ごとに異なります。異なる系列をつなぐときは注意してください。
