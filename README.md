# 世界経済論考

経済の分析と思想的な文章を発信するための個人ブログ。Astro で静的サイトを生成し、GitHub Pages（https://kazuma-2003.github.io/）で公開する。

## 管理画面（ふだんはこちら）

`ブログを書く.bat` をダブルクリック → ブラウザに管理画面（http://localhost:4400）が開く。使い終わったら黒い画面を閉じる。

- **一覧**：公開中・下書き・非公開で絞り込み、検索できる。「未反映の変更」は手元で直してまだ公開に反映していない記事
- **新しい記事**：「ブラウザで書く」か「Word から取り込む」（画面に .docx をドロップしても良い）
- **編集**：Word に近い見たままのエディタ。「/」で見出し・表・数式・画像などを挿入。Ctrl+S で保存
- **プレビュー**：実際のブログと同じ見た目で確認（下書きも見られる）
- **公開する／変更を公開／再公開する**：GitHub に送り、1〜2分でブログに反映
- **…メニュー**：Word で本文を置き換える／一時非公開にする／削除する（`trash/` に移るので取り出せる）

### Word で書くときのコツ

- 1行目を「表題」スタイルにするとタイトルとして読み取られる（無ければ最初の見出し）
- 章は「見出し 1」、節は「見出し 2」
- 数式は Word の数式エディタ、脚注は「参考資料 → 脚注の挿入」、表・図はそのまま貼ってよい（図のキャプションも取り込まれる）
- 「＊＊＊」だけの段落は区切り線になる

## 記事の置き場所

| 場所 | 中身 | GitHub に送るか |
|---|---|---|
| `src/content/posts/` | 公開中の記事 | 送る |
| `src/content/private/` | 下書き・一時非公開の記事 | 送らない |
| `public/images/<記事名>/` | 記事の画像 | 公開中の記事のものだけ送る |
| `trash/` | 削除した記事 | 送らない |

記事のファイル名（URL名）がそのまま URL（`/posts/<URL名>/`）になる。公開後は変えない。

## Markdown で直接書く場合

```
npm run new -- ファイル名 経済分析   # 分類は 経済分析 / 思想 / 雑記
```

`src/content/private/ファイル名.md`（下書き）ができる。公開は管理画面から行う。

- 数式: 文中 `$...$`、独立 `$$...$$`（KaTeX）
- 脚注: `本文[^1]` と `[^1]: 注`
- 画像: `![](/images/記事名/名前.png "図の説明")`（段落に画像だけなら図とキャプションになる）

## 開発

```
npm run dev            # http://localhost:4321（下書きも表示）
npm run build          # dist/ に本番用を生成（下書きは除外）
npm run admin          # 管理画面だけを起動（ブログを書く.bat と同じ）
npm run build:editor   # 管理画面のエディタを作り直す（tools/writer/editor-src.js を変えたとき）
```

- ブログ名・著者: `src/consts.ts`
- デザイン: `src/styles/global.css`
- 管理画面: `tools/writer/`（サーバー `server.mjs`、画面 `index.html`、Word 変換 `convert.mjs`。Word 変換は Pandoc を使用：`winget install JohnMacFarlane.Pandoc`）
- 公開: `main` への push で `.github/workflows/deploy.yml` が自動デプロイ
